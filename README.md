<summary>🐍 Bonus: animated contribution snake (click to set up)</summary>
<br/>

GitHub's classic "snake eats your contribution graph" animation. Since it needs a scheduled job, it isn't plug-and-play like the badges above — a one-time setup in your `nerdthingz/nerdthingz` repo makes it work:

1. Create `.github/workflows/snake.yml` in this repo with:

```yaml
name: Generate Snake Animation
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch: {}
  push:
    branches: [ "main" ]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: nerdthingz
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

2. Once it runs once, add this to your README where you want the animation:

```md
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/nerdthingz/nerdthingz/output/github-contribution-grid-snake-dark.svg" />
  <source media="(prefers-color-scheme: light)" srcset="https://raw.githubusercontent.com/nerdthingz/nerdthingz/output/github-contribution-grid-snake.svg" />
  <img alt="snake animation" src="https://raw.githubusercontent.com/nerdthingz/nerdthingz/output/github-contribution-grid-snake.svg" />
</picture>
```
